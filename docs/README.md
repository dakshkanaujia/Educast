## Notes

- **Supervisor signature (item 1):** the report includes a sign-off block for the supervisor to complete. The actual signature must be added by the supervisor — it cannot be generated here.
- **Validation results are real:** the test/validation report reflects an actual run of `../scripts/api_test.sh` against the live Dockerised stack (**33/33 passed**). Re-run it any time to reproduce.
- **Plagiarism report (item 6):** this is a signed *compliance declaration*. The official machine-generated similarity report is produced by the institution's plagiarism tools; the declaration states the author's compliance and consent to that process.
- Fill in the placeholder fields (supervisor name, signatures, dates) before final submission.
